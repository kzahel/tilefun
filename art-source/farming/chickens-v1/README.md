# Farm chicken sprites v1

Original pixel art for the rooster, chick and egg. The four bird rows face
down, up, left and right. Each row contains idle, four walk frames and two
stationary action frames. The egg row contains an ordinary egg, a fertile
egg and a broken shell.

Regenerate the exact draft PNGs with
`node art-source/farming/chickens-v1/draw.mjs` using the repository's installed
dependencies. The game loads the checked-in output under
`public/assets/farming/`.
