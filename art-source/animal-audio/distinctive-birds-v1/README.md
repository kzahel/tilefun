# Distinctive bird recordings v1

Six identified real bird sources provide eleven excerpts: Indian peacock, macaw,
wild turkey, sparrow, flamingo and African penguin. Sparrow (George Papargyris)
and African penguin (Vortichez) are CC BY 4.0; the other four are CC0. All raw
files are exact public HQ MP3 previews, not original lossless uploads. Provenance
and manifest retain creator/source/license/download URLs, hashes, exact edits and
signal measurements. Public [credits](../../../public/assets/audio/animals/CREDITS.txt)
are linked from Animal Browser and describe the edits without implying endorsement.

Peacock calls only on fresh existing courtship-display onsets, with a thirty-second
cooldown and no idle calls. Two natural phrase excerpts are selected from Kinoton's
isolated male recording; that source already contains denoise/EQ/reverb. Macaw,
sparrow, flamingo and penguin use sparse stationary calls. Turkey also admits its
existing generic action pose, with a forty-five-second cooldown. Parrot/sparrow
stop while carrying objects. Calls stay quiet during ordinary travel, feeding and
unrelated work; no new bird AI, imitation speech or nesting actions are implied.

Macaw is explicitly Ara, not a human talking-parrot imitation. The sparrow source
does not identify an exact scientific species, so the generic game bird carries
that qualification. Flamingo is likewise generic, with multiple birds in the
source. Penguin explicitly uses African penguin field calls from Boulders Beach;
its selected bray retains colony background. This is a stated interpretation of
the generic game penguin, not an emperor-penguin species claim. Owner listening
should assess those backgrounds and the source peacock reverb.

Species filters, mono 24 kHz, RMS target 0.16/source peak limit 0.75, quiet edges
and Vorbis quality 4. Exact recipes/metrics are retained. No pitch variants,
human imitations or transformed other-species calls. Source descriptions,
waveforms/spectra and output signal limits were checked; **owner listening review
remains pending**. Builds consume frozen outputs and never run the explicit
single-bank exporter. See [campaign delivery](../../../docs/tactical/185-overnight-animal-voices.md).
