# Raptor and grazing mammal recordings v1

Six CC0 sources/eleven excerpts cover owl, eagle, hawk, camel, warthog and
American bison. Exact public HQ MP3 previews, source pages, creator/license
links, hashes, selected ranges, processing and decoded measurements are retained.
These previews are not described as original lossless files.

The generic owl/eagle/hawk identities use explicitly labeled tawny owl, bald
eagle and red-tailed hawk calls. They play only at fresh existing display poses,
with no ambient calls or old synthesized layer. Hawk is a real-species archival
USC sound-effects recording from the 1930s–1960s, not a new field recording.
Archival/field noise remains a listening-review concern.

Camel groans are sparse stationary calls and an existing generic action cue;
the uploader does not identify a camel subspecies. Warthog has a short grunt.
Bison's nasal huffs are explicitly non-vocal breath sounds, with sparse
stationary playback. No new AI, aggression, breath animation or alarm behavior
is implied by these recordings.

Filters retain each sound's useful band, followed by mono 24 kHz conversion,
RMS target 0.16 limited by source peak 0.75, quiet edges and Vorbis quality 4.
No artificial pitch variants or other-species substitutions. Source identity,
waveforms and decoded signal limits were checked; **owner listening review
remains pending**. Frozen assets are consumed without downloading/re-encoding.
