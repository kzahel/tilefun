# Working wheel-lift tow truck v2

Exact additive equipment revision of retained v1. Original body/UVs, atlas and
four wheel rigs remain unchanged. Two new rigid draw groups add the telescoping
steel arm and universal axle cradle. The constructor and hashed inputs/outputs
are in `recipe.json`; `car.blend` has packed textures and `model.glb` is embedded.

`scripts/vehicle-bake/tow-truck/equip.py` replays into a fresh output directory.
Default retained outputs are immutable. Game controls, fitted axle contacts and
fallback capture/replay follow [the towing workflow](../../../../docs/vehicle-towing.md).
New poses await owner inspection; original v1 receipts are unchanged.
