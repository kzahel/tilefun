Its own GLB contains only the bike, 2434 triangles, three draw meshes and one opaque nearest/unlit 512 atlas. The packed master preserves 55 editable semantic components; the low preserves the actual three runtime meshes.

It is neither re-exported nor embedded into this bike GLB. The composition uses its original measured profile and a single source translation `[.12,0,1.1205]`.
