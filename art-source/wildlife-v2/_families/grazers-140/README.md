# Grounded grazer source family, tactical 140

Independent empty-scene donkey/mule/llama/alpaca anatomy with fixed-length
limbs, two-link necks, separate heads/jaws, source tails and independent hooves.
The 64px cell retains the shared camera and 10px/world-unit scale. Profiles own
coat, barrel/neck/head/ear proportions and per-species walk travel. Llama neck
length and alpaca head height were corrected after native silhouette review;
donkey grey contrast was strengthened before registration.

Every body carries buried shoulder/hip roots above planted hooves. The neck
base follows the torso and its constant-length links carry the head through
grazing. Dense action keys avoid interpolated gaps and native jaw samples retain
the chew. Camelids have actual paired-toe meshes, equines full oval hooves.
Source paint uses separate rigid coat/face/jaw masters, actual neck/tail joints,
and exact rounded source foot silhouettes. Compact native foot hulls replace
redundant per-pose mesh vertex clouds without changing output pixels; the full
rig geometry remains in Blender and is independently audited.

Per-species inputs pin this family and the camera. Registered files are
immutable; use a separate family/revision for future changes. The optional
WILDLIFE_OUTPUT_DIR isolates draft work. Normal builds consume committed banks.
Every new exact identity remains pending human review.
