# Feline source family, tactical 140

Empty-scene Blender anatomy, palette projection and independent saved-scene
mechanics audit. Distinct builds: broad rosetted jaguar; slender long-tailed
leopard; tall, spotted cheetah with tear marks; tufted, large-pawed Eurasian lynx;
and shorter-tufted warm-coated bobcat. Fixed-length limb chains connect buried
shoulders/hips to independent planted paws. Tapered articulated tails, torso
heave/pitch, head counter-motion and a separate feeding/growling jaw retain
constant local geometry and scale. These are stylized game gaits.

Walk and chase use separate 32-pose travel cycles. Cheetah chase poses last 15ms;
other chase poses last 20ms. Independent audit samples 129 points per gait and
33 per action/facing. Compact projected hulls preserve paw and tail volume;
coat marks follow the actual moving body. No historical source or pixels read.

Registered inputs and receipts are immutable. WILDLIFE_OUTPUT_DIR isolates
previews. Normal builds use committed assets. Agent inspection, replay and game
checks do not approve art: exact final pixels remain pending human review.
