# Ocean hunters, autonomous run 140

Fresh editable shark, hammerhead and orca scenes use a rigid body, three fixed
tail links, attached rotating pectoral fins, a linked jaw and a terminal tail.
Sharks sweep a vertical tail laterally; the orca moves horizontal flukes vertically.
The saved scenes key idle, swimming, feeding, display and independent fast pursuit.
They use the shared four-facing camera at ten native pixels per world unit.

The independent audit reopens saved Blender scenes, samples quarter poses, checks
constant local mesh coordinates/scales, tail endpoints, fin roots and loop closure,
and measures actual projected body motion. Source projections paint the native
fixed-palette binary-alpha pixels; no image generation or posed image warping.
Exact registered banks and this shared input set become immutable at registration.
Mechanical checks do not confer human art approval.
