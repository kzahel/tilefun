# Long-legged birds, continuation147

Flamingo, shoebill, secretary bird, marabou stork and great blue heron use buried
four-link biped legs, planted contacts and moving torsos. Three fixed neck links
and overlapping joint bulbs maintain head/body connection while bending into
forage poses. Distinct bills, head/wing/tail markings and crests are editable source
geometry. Secretary bird additionally has display/chase clips for terrestrial
hunting. The other four use grounded walking/foraging; wetland wading and flight
are future work. Existing banks remain frozen. New exact pixels pending review.
