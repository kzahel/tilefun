# Small mammals, autonomous run 140

Ten fresh editable scenes share independently auditable four-link limbs, buried
shoulder/hip roots, four planted feet, rigid moving bodies, articulated heads/jaws
and fixed linked tails. Each scene has 32 walk poses and eight foraging poses per
facing, with matched source travel and runtime speed at ten pixels per world unit.

Species geometry varies skull, muzzle, ears, cheeks, body/leg proportions, paws,
tail length/radius/posture, quills, masks and coat patches. Hamster cheek pouches,
guinea-pig blaze/patch and short tails, mouse/rat whiskers and bare tails,
chinchilla ears/furry tail, hedgehog/porcupine quills, raccoon mask/ringed tail,
skunk paired back stripes/plume and red-panda mask/dark limbs/ringed tail are
authored meshes/materials. Tail bands paint visible source surface faces.

The independent audit reopens the saved scenes and checks quarter-pose endpoints,
fixed local geometry/scales, contact, planted travel and loop closure. Native
finishing uses actual posed source mesh projections, with fixed palette, binary
alpha and a one-pixel boundary. Mechanical checks do not confer human approval.
Exact banks and all pinned helper inputs become immutable at registration.
