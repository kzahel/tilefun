and breast, compact wings, short tail and orange webbed feet.

elbow wings retain fixed volumes and connected parent roots. Landing-to-landing
flights tuck feet and flap wings with actual shared authority lift. Separate jaw
and head action. Four facings, native/3x playback, fixed palette/binary alpha,
byte-identical explicit source replay. Exact new pixels pending human review.
