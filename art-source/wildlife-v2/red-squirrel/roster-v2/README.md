# Fresh red squirrel prototype

Tactical 140 authorizes this separate roster-v2 identity. The builder starts
from an empty Blender scene and reads no historical squirrel source/pixels.
Species anatomy includes slim russet torso/haunches, cream throat/belly, small
pointed muzzle, tufted ears and a four-section curled bushy tail. Four fixed-
length links per leg carry independent paws from buried shoulder/hip points.
Body compresses/pitches through the bound, with fixed-volume fur throughout.

Native 48px cell, (24,35) anchor, shared 10px/world-unit camera. The 32-pose
640ms bound matches shared physical motion: push .10s, landing .54s, height
6px. Paws tuck in flight and return to grounded supports. The feeding action
rears the chest, lifts both forepaws and a visible chestnut to the muzzle,
then lowers them. Actual forelimb solving preserves link lengths; hind feet
stay planted. Source is 100fps, two frames/bound pose and ten/action pose.

Rest-only body/head volume guides author retained palette-letter paint once;
actual joints/tail/nut records drive other pixels. This avoids dense per-pose
vertex bundles. Native character-scale scene uses the same foot baseline.
Independent audit checks 65 half-poses/facing plus 17 feeding half-poses,
2,688 fixed limb links, 280 ground contacts and 672 tail links. Maximum
interpolated endpoint separation is 0.0234 world units (under 0.24 native px);
geometry/scale remain constant and both loops close exactly. Pixel finishing
requires palette/binary alpha, padding and native torso-paint motion. Explicit
replay and Chromium verify exact assets. Ordinary builds use committed banks;
changed pixels have their own pending human review identity.
