# Fresh eight-arm octopus prototype

Tactical 140 authorizes a separate roster-v2 identity. The builder starts with
an empty Blender scene; it reads no historical octopus source or pixels.
A rounded rust mantle, upper mantle planes, crown, paired golden slit eyes
and siphon sit above eight independent five-link arm chains. Each arm has
separate narrowing volumes and attached sucker geometry. This is stylized
game motion, not a measured reconstruction of cephalopod musculature.

The 48px cell and (24,35) anchor preserve the shared 10px/world-unit camera.
The 32-pose jet cycle lasts 960ms. Mantle heave/pitch accompanies staggered
waves through all eight arms. An eight-pose curl action draws the tips inward.
The saved Blender scene owns all motion with intermediate source keys;
local mesh geometry and object scales stay constant. Rigid mantle palette
paint follows the actual projected body basis; articulated arm paint and
suckers follow their own evaluated source joints. Export/playback math is
reused, while species geometry and painted parts are independently authored.

Source audit, explicit replay, native/enlarged visual inspection, full Chromium
playback and shared world/game checks must pass before registration. Exact
final pixels remain pending human review. Ordinary builds use committed assets.

For draft authoring, WILDLIFE_OUTPUT_DIR can point to an isolated preview
folder so another batch's normal build never indexes unfinished output.
The final default output remains public/demos/wildlife-v2/octopus/roster-v2.
The independent saved-scene audit samples 129 points per jet/facing and 33
per curl/facing, checking 13,120 fixed arm links, buried arm roots, constant
local geometry/scales, smooth rotations and exact loop closure. Maximum
interpolated endpoint separation is under .001 native px, and mantle anchor
motion remains above 1px in all four projections.
