# fox behavior-v1

Owner-authorized tactical 174. Pending human review. Listen, stalk and physically pounce on real small prey; eat only actual catches.

Retains the original native motion cells byte-for-byte, at the same palette,
canvas and ground anchor. New action timeline starts at frame 500; inspect the
separate retained original scene for native travel. Existing mesh vertices,
scale, limb lengths and camera stay fixed. New controls articulate the body,
connected neck, independent grounded feet and attached quills where applicable.
The fox's real world-space leap is owned by shared fauna motion, not sprite bob.

Sources and palette/input hashes are in inputs.json. Source audit independently
reopens the saved scene and checks link endpoints, hip and neck attachments,
planted feet and quill roots. Pixel audit checks padding, binary alpha, changing
poses and connected head/body paint; native and enlarged full Chromium compare
all chronological cells. Explicit minimal-input replay must be byte-identical.

Run `python scripts/wildlife/threat-replay.py fox --check` to check the retained
bank. Ordinary builds use committed art and never regenerate these identities.
Changed pixels require a new identity and human review; no approval is inferred.
