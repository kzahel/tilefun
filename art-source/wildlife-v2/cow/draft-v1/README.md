# Holstein cow draft-v1

Fresh full48-mesh editable cow.blend and standalone repeatable build.py,100 independently projected poses. Fixed accepted wildlife-v2 camera:40 degrees ABOVE GROUND (polar50), yaws180/0/100/260;10px/unit,64px square, ortho6.4, ground anchor(32,46), shiftY14/64. Full mesh vertices remain only in the blend; projected guides serialize compact hulls/bounds/landmarks/contacts.

Three fixed leg links: fore0.46/0.48/0.68; hind0.47/0.48/0.66. Distinct paired hoof toes, lateral ears, pink muzzle/udder and three articulated tail links0.38/0.40/0.30. Sixteen-pose slow four-beat walk,12stance samples per hoof, three supports; separate preview travel matches subsequent hind/front print replacement. Eight-pose fly-swat action; head and marking geometry never scales.

author-masters.py retains deliberately authored Holstein palette-letter patterns, not render quantization or animal recolors. finish.py composes native pixels from independent guides; skull and torso share an integer rounding phase. audit.py opens the saved blend read-only in a fresh process. verify.py checks replay/decoded head-and-coat/GIF/browser outputs. capture.mjs uses bundled Chromium and owned browser/server cleanup, including a negative-timestamp reset regression. Source helpers borrowed only export/review plumbing, not pending/rejected animal pixels or proportions.

Precise inspection and limitations: public/demos/wildlife-v2/cow/draft-v1/review-observations.md. Human review pending; new changes after registration require a new revision.
