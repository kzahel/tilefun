# Fresh cheetah source

Tactical 140 authorizes this distinct roster-v2 identity. This wrapper starts
an empty Blender scene using pinned felids-140 mechanics and species-specific
anatomy, palette, coat marks and travel parameters. Camera: 10px/world unit,
64px cells, (32,48) anchor. Idle, 32 walking, eight feeding, eight growling and
32 chase poses per facing. Separate torso/head/jaw and four fixed links per
limb carry independent planted paws. Tail chains taper with species anatomy.

Independent audit checks continuous linked motion, root coverage, contacts,
travel, fixed meshes/scales and exact loops. Native/enlarged inspection,
deterministic replay and Chromium playback precede registration. Shared runtime
hunts explicit legal prey; natural victims replace their lineage, manual ones
stay gone. Exact final pixels remain pending human review.
