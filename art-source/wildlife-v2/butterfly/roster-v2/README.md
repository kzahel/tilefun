# Fresh monarch-like butterfly prototype

Tactical 140 authorizes this separate roster-v2 identity. The builder starts
from an empty Blender scene and reads no previous butterfly source or pixels.
Four independently hinged fixed wing panels carry editable orange cells, dark
borders/veins and cream marginal spots on both surfaces. Slim abdomen/thorax,
clubbed antennae, six articulated legs/foot pads and a three-part coiling
proboscis remain separate geometry. Wing decals follow actual panel facing
and deliberate paint order; no rendered colours are quantized.

Native cell 32px, (16,24) ground anchor, shared 10px/world-unit camera. Basking
rest keeps the wing identity readable. The 32-pose/640ms flutter has two wing
beats, tucks the six legs, and returns to the same pose. Production uses shared
bounded airborne arcs: push .04s, landing .60s, height 6px, total .64s. It
lands/rests between trips and can be hunted while grounded. Feeding action
uncoils the proboscis and gently flexes resting wings; idle/action use 100ms
poses. Source timing is 100fps, two frames/flutter pose and ten/action pose.

Compact independently projected hulls drive native palette-letter frames.
The saved-scene audit checks 65 half-poses/facing, fixed geometry/no scale keys,
1,040 rigid wing distances, loop closure, visible projected wing travel and
24 exact resting foot contacts. Pixel checks require binary alpha, four-color
palette, padding and at least eight distinct native flutter poses per facing.
Replay and Chromium compare exact outputs at native/3x. Ordinary builds use
committed assets. Human art review remains pending.
